## Summary
This is a Simple Math Tutor for young children. In version 4, every question the player is asked is stored in a 2D vector, and a formatted summary report is displayed when the player decides to quit.

The program:

- Displays a header and silly math facts

- Prints 3 random math facts;

- Ask for user name;

- Welcome user to program

- Uses random lib to create the math operation

- Uses random lib to create the math question numbers between (1-10)

- Checks for no negative or fractions

- Provides three attempts for the user

- Check if user still wants to play

- Levels up after five correct questions

- Levels down after five wrong questions

- Stores every question (level, left number, math symbol, right number, correct answer, attempts) in a 2D vector

- Displays a summary report with total questions, total correct, total incorrect and average correct when the user quits

- Finishes the program after user decides to stop
